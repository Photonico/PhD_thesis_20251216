# PhD Thesis

My PhD thesis on Computational Condensed Matter Physics at the University of Sydney

Lu Niu

Build from the repository root with `latexmk -r source/.latexmkrc` (pdfLaTeX and Biber). The main file is `source/thesis.tex`. LaTeX Workshop
uses the same build and opens `.output/thesis.pdf`. The log and SyncTeX
file are in `.output/`; intermediate files are in `.output/.build/`.
